# 코딩 채팅 1: 빈 Android 프로젝트 + Actions 빌드·서명

## 목표
- 빈 화면 하나 뜨는 Kotlin + Jetpack Compose Android 프로젝트 생성.
- GitHub Actions: PR·`main` 푸시 시 디버그 빌드 검사, `v*` 태그 푸시 시 서명 릴리스 APK를 GitHub Releases에 업로드.
- 서명 키 생성·Secrets 등록 절차 문서(`docs/signing.md`). 키 자체는 사용자가 직접 생성·등록.

## 완료 기준 (확인 가능한 항목)
- [ ] 저장소 루트에 Gradle 프로젝트(Kotlin DSL, Version Catalog, Gradle Wrapper 포함). 모듈은 `app` 하나.
- [ ] 패키지명·applicationId `io.github.ares_wjd.nihongo`, minSdk 26, targetSdk·compileSdk 35.
- [ ] 앱 실행 시 Compose 화면에 "nihongo" 텍스트 표시(Material 3).
- [ ] `.github/workflows/ci.yml`: PR·`main` 푸시 시 `./gradlew assembleDebug` (가능하면 `lint`/`test`도) 성공. 작업 브랜치 PR에서 녹색 확인.
- [ ] `.github/workflows/release.yml`: `v*` 태그 푸시 시 Secrets로 서명한 `assembleRelease` → 해당 태그 Release 생성, APK 첨부(`nihongo-<버전>.apk`).
- [ ] 버전: versionName은 태그에서 `v` 제거한 값, versionCode는 `github.run_number`. Gradle 속성(`-PversionName`, `-PversionCode`)으로 주입, 미지정 시 기본값(`0.0.0-dev`, 1).
- [ ] 서명 설정은 환경변수(`KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)에서 읽음. 없으면 release 서명 없이 빌드(로컬·CI 디버그용으로 실패하지 않게).
- [ ] `docs/signing.md`: 키 생성(`keytool`), base64 변환(Windows/macOS/Linux), Secrets 4개(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) 등록 경로, 원본 키 백업 필요성(분실 시 업데이트 불가), 릴리스 방법(태그 푸시) 기재.
- [ ] 비밀 파일 커밋 없음(`.gitignore`에 Android 빌드 산출물·`local.properties` 추가).

## 다른 기능과의 접점 (데이터 형식, 인터페이스)
- 이후 단계에서 Room·FSRS·네트워크 의존성을 추가함 → 의존성은 Version Catalog로만 관리.
- 5단계 앱 업데이트 버튼이 Releases 최신 릴리스의 APK 첨부 파일과 versionCode/태그를 비교함 → 릴리스마다 APK 1개 첨부, 태그 형식 `vX.Y.Z` 유지.
- 서명 키는 모든 릴리스에서 동일해야 함(업데이트 설치 조건).

## 작업 순서
1. 환경 확인: JDK 17, Android SDK 유무. 없으면 로컬 빌드는 생략하고 Actions 결과로 검증(그 사실을 결과에 기록).
2. 프로젝트 골격·Wrapper 생성. Wrapper jar는 `gradle wrapper` 또는 공식 배포본에서 확보(손으로 만든 jar 금지). AGP·Kotlin·Compose BOM은 서로 호환되는 안정 버전.
3. `MainActivity` + Compose 테마 최소 구성.
4. 버전 주입·서명 설정을 `app/build.gradle.kts`에 작성.
5. `ci.yml`, `release.yml` 작성(`actions/setup-java` + `gradle/actions/setup-gradle`, release는 `permissions: contents: write`).
6. `docs/signing.md` 작성.
7. 작업 브랜치 푸시 → PR 생성 → CI 녹색 확인(실패 시 수정 반복). chat-close로 병합·완료 보고.

## 주의
- 태그 푸시·Secrets 등록은 이 채팅에서 하지 않음(사용자 키 등록 후 메인 채팅이 첫 릴리스 진행).
- 키스토어·비밀번호를 저장소·로그에 남기지 않음. release.yml에서 base64 복원한 키 파일은 `$RUNNER_TEMP`에 두기.
- 패키지명에 하이픈 불가 → `ares_wjd` 사용.

### 검증
- 로컬: Android SDK(platform 35, build-tools 35.0.0)를 컨테이너에 설치해 `./gradlew assembleDebug lint test assembleRelease` 성공.
- 임시 키(`keytool`)로 `-PversionName=1.2.3 -PversionCode=42` 서명 빌드 → apksigner 서명 확인, aapt로 versionCode 42 / versionName 1.2.3 / 패키지명 확인. 임시 키는 저장소 밖에서 생성, 커밋 안 함.
- CI: PR Ares-wjd/nihongo#2 `build` 성공.

### 결정 사항
- 버전: AGP 8.10.1, Kotlin 2.1.21(Compose 컴파일러 플러그인), Compose BOM 2025.05.01, core-ktx 1.16.0, lifecycle 2.9.0, activity-compose 1.10.1. compileSdk 35와 호환되는 범위로 선택(더 최신 androidx는 compileSdk 36 요구).
