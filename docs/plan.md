# 확정 계획

## 전제
- 사용자 1명, Android 기기, 공개 저장소. 대중 배포 없음.
- 수준: 가나 읽기 가능, 단어 부족 → N5 기초부터.

## 스택
- Kotlin + Jetpack Compose, Room(SQLite), FSRS(간격 반복).
- 빌드: GitHub Actions → GitHub Releases에 서명 APK.
- 서명 키는 GitHub Secrets에만. 키 동일해야 업데이트 가능.

## 브랜치
- 기본 브랜치 `main`. 채팅마다 자기 작업 브랜치 → 종료 시 PR 생성 후 채팅이 직접 `main`에 병합.

## 설치·업데이트
- 최초: Releases 링크로 APK 설치.
- 앱 업데이트 버튼: 최신 릴리스 조회 → APK 다운로드 → 설치 화면(사용자 1회 탭 필요).
- 단어장·음성: 저장소 파일 교체 → 앱이 버전 확인 후 내려받기·캐시(오프라인 동작).
- 학습 기록: 기기 내 Room. 백업 내보내기/가져오기 제공(앱 삭제 시 소실 대비).

## 학습 기능
### 단계(숙련도) → 문제 유형
| 단계 | 유형 |
|---|---|
| 0 | 짝 맞추기(한·일 카드 연달아 클릭) |
| 1 | 일본어 보고 한국어 고르기 |
| 2 | 한국어 보고 일본어 고르기 |
| 3 | 발음 듣고 단어 고르기 |
| 4 | 일본어 보고 한국어 타이핑 |
| 5 | 한국어 보고 가나 조립 |
- 정답 → 단계↑, 복습 간격↑ / 오답 → 단계↓, 곧 재출제. 간격은 FSRS로 계산.
- 오답 보기: 품사·형태·뜻이 비슷한 단어 우선.
- 한국어 타이핑 채점: 단어별 인정 뜻 여러 개, 띄어쓰기 무시, 목록 외는 오답. 수동 정답 처리 버튼 없음.
- 가나 조립: 읽기(가나)로 조립, 한자 단어는 정답 후 한자 표기만 표시. 오답 타일은 혼동 글자(シ/ツ, ソ/ン, ぬ/め, わ/ね/れ, は/ば/ぱ, つ/っ, や/ゃ, ー 등) 위주로 정답 글자 수의 1.5~2배.
- 예문: 단어별 1개 이상(일본어+번역).
- 오답 노트.

### 모드
- 스테이지 모드: 단어장 선택, 그 안에서 신규·복습.
- 무한 모드: 전체 단어장의 복습 대상 우선, 남는 자리를 기초 순서대로 신규 단어로.
- 하루 신규 단어 상한(기본 10~15, 설정 가능).

## 단어 데이터
- N5부터 주제별 단어장(인사, 숫자, 음식, 가족, 기본 동사 등).
- 필드: id, 표기(한자), 읽기(가나), 인정 뜻[], 품사, 급수, 태그, 예문[], 음성 파일.
- Claude가 생성 → 검수 기준에 따라 확인.

## 음성
- Google Cloud TTS(무료 한도 내)로 사전 생성한 mp3를 저장소에 둠. 입력은 가나(오독 방지).
- 억양 이상한 단어는 개별 교체 가능 구조.
- 무료 한도·음성 종류는 계정 생성 시 재확인.
