# 채팅 종료
1. 작업 채팅:
   - 명세의 완료 기준 확인. 테스트·빌드 결과 보고(실패 시 그대로).
   - `docs/tasks/<이름>.md` 끝에 `## 결과` 추가: 바뀐 파일, 결정 사항, 남은 일, 다른 작업에 영향 주는 점.
   - `docs/chats.md` 상태 "완료".
2. 메인 채팅:
   - `docs/status.md` 갱신: 완료/다음 할 일/미결정. 새 채팅이 이것만 읽고 이어갈 수 있게.
   - 확정 결정은 `docs/plan.md`에 반영.
   - `docs/chats.md` 갱신.
3. 커밋 후 푸시.
4. 사용자에게 안내: "이 채팅 보관 → 새 채팅에서 `이 채팅은 X채팅이야.`" (다음 채팅 이름 명시).
