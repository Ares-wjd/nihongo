# 작업 명세 작성
1. 번호: `docs/chats.md`에서 같은 종류의 마지막 번호 +1.
2. `docs/tasks/<종류>-<N>.md` 작성. 작업 채팅은 앞선 대화를 모르므로 이 파일만으로 작업 가능해야 함.
   ```
   # <종류> 채팅 N: <주제>
   ## 목표
   ## 완료 기준 (확인 가능한 항목)
   ## 읽을 문서·파일 (최소한)
   ## 건드릴 파일·폴더
   ## 다른 기능과의 접점 (데이터 형식, 인터페이스)
   ## 작업 순서
   ## 주의
   ```
3. `docs/chats.md`에 행 추가(상태 "대기").
4. 커밋 → PR → `main` 병합(chat-close 3번과 동일) 후 첫 프롬프트(`이 채팅은 <종류> 채팅N이야.`)를 코드블록으로 제시하고 새 채팅 열라고 안내. 병합 전에 작업 채팅을 열면 명세가 안 보임.
