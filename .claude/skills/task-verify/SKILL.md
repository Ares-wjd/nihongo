# 작업 결과 확인 (메인 채팅 전용)
1. `git pull`로 최신 `main` 받기. `docs/tasks/<이름>.md`의 `## 결과` 읽기.
2. 완료 기준을 항목별로 실제 확인: 파일 존재, 테스트·빌드 실행(가능한 범위), 명세와 다른 점.
3. 판정 보고(첫 줄에 통과/미흡, 근거는 핵심만):
   - 통과: `docs/chats.md` 상태 "확인 완료", `docs/status.md` 갱신, 커밋·병합. "해당 작업 채팅 보관 가능" 안내 후 다음 작업으로.
   - 미흡: 문제 목록 보고. 수정은 보정 명세(`task-spec`)로 새 작업 채팅에 배정하거나, 사용자가 기존 작업 채팅을 다시 쓰도록 제안.
4. 다음 작업 채팅이 필요하면 `task-spec`으로 명세 작성·병합 후 아래 형식으로 안내:
   ````
   새 채팅을 열고 첫 프롬프트로 입력:
   ```
   이 채팅은 코딩 채팅N이야.
   ```
   ````
