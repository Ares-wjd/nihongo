# 채팅 시작
1. 메시지에서 채팅 이름 파악(메인 / 코딩N / 디자인N / 기능N).
2. 메인:
   - `docs/status.md`, `docs/chats.md` 읽기. `docs/plan.md`는 필요한 절만.
   - 현재 상태와 다음 할 일을 짧게 보고.
3. 작업 채팅:
   - `docs/chats.md`에서 해당 채팅 행 확인, `docs/tasks/<종류>-<N>.md` 읽기.
   - 명세가 없으면 작업하지 말고 "메인 채팅에서 명세 먼저 작성 필요"라고 보고.
   - 명세에 적힌 파일·문서만 읽기. 저장소 전체 탐색 금지.
   - 명세 요약(목표·완료 기준·작업 순서) 보고 후 시작.
4. `docs/chats.md`의 해당 행 상태를 "진행"으로 변경.
